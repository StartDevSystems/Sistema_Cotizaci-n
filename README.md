# ☀️ BlueSky Energy - Sistema de Cotizaciones (V2.2 PREMIUM MOBILE)

Sistema integral de gestión de clientes y generación de cotizaciones para **BlueSky Energy**. Evolucionado a una interfaz **Ultra-Premium** con tecnología 3D y optimización móvil avanzada.

🚀 **URL en vivo:** [https://sistema-cotizaci-n.onrender.com](https://sistema-cotizaci-n.onrender.com)

## ✨ Características de la Versión 2.2 (Actual)

*   **📱 Mobile-First Pro:** Todas las páginas cuentan con una **barra de navegación inferior (Bottom Nav)** en dispositivos móviles para una navegación ergonómica con el pulgar.
*   **🌌 Ecosistema 3D Unificado:** Fondo interactivo de red eléctrica tridimensional en todas las vistas (Dashboard, Nueva Cotización, Clientes, Listado).
*   **💎 Diseño "Duro" (Premium Glassmorphism):** Interfaz oscura unificada con efectos de cristal, desenfoque de fondo y bordes suaves.
*   **📐 Escala Real (Imponente):** Tipografía base aumentada a **18px/20px** y elementos visuales escalados para máxima presencia en monitores grandes.
*   **🎭 Animaciones Cinemáticas:** GSAP integrado para contadores de dinero y entradas de tarjetas fluidas.
*   **🛡️ Blindaje de Inputs:** Eliminación total de fondos blancos en tablas y formularios; modo oscuro puro garantizado.
*   **📄 Branding Consolidado:** Uso total del Logo 1.2 PNG con transparencia en web, PDF y Excel.

## 🛠️ Tecnologías Utilizadas

*   **Backend:** Python 3.11 + Flask + Docker.
*   **Visuales:** Three.js, GSAP, Chart.js.
*   **Frontend:** HTML5, Bootstrap 5, Custom CSS Moderno.
*   **Datos:** Firebase Firestore.

## 🚧 Próximas Mejoras (Roadmap)

1.  **Seguridad Pro:** Implementar **Firebase Auth** para acceso restringido con usuario y contraseña.
2.  **Automatización:** Envío automático de cotizaciones por Email (vía API de correo).
3.  **Firma Digital:** Integración para que el cliente pueda firmar la cotización desde el navegador.
4.  **Portal del Cliente:** Link único para que los clientes vean y aprueben sus cotizaciones en línea.

## 💻 Instalación Local

1. **Clonar:** `git clone https://github.com/StartDevSystems/Sistema_Cotizaci-n.git`
2. **Entorno:** `python -m venv venv` -> `.\venv\Scripts\activate` -> `pip install -r requirements.txt`
3. **Ejecutar:** `python app.py`
