# ☀️ BlueSky Energy - Sistema de Cotizaciones (V2 PREMIUM)

Sistema integral de gestión de clientes y generación de cotizaciones para **BlueSky Energy**. Evolucionado a una interfaz **Ultra-Premium** con tecnología 3D y animaciones cinemáticas.

🚀 **URL en vivo:** [https://sistema-cotizaci-n.onrender.com](https://sistema-cotizaci-n.onrender.com)

## ✨ Características de la Versión 2.0 (Actual)

*   **🌌 Visuales "Duros" (3D Environment):** Fondo interactivo de red eléctrica tridimensional desarrollado con **Three.js** que reacciona al movimiento del mouse.
*   **💎 Glassmorphism Design:** Interfaz unificada con efectos de cristal, desenfoque de fondo y bordes de neón.
*   **🎭 Animaciones GSAP:** Entrada fluida de elementos, contadores de dinero animados y transiciones profesionales.
*   **📊 Dashboard de Alto Rendimiento:** Sidebar lateral moderno, métricas en tiempo real y gráficas optimizadas para modo oscuro.
*   **📄 Generación de Documentos V2:** PDFs y Excels con el nuevo branding corporativo (Logo 1.2 PNG).
*   **📱 Responsive & Adaptive:** Diseño corregido para una visualización perfecta tanto en PC como en dispositivos móviles.

## 🛠️ Tecnologías Utilizadas

*   **Core:** Python 3.11 + Flask.
*   **Visuales:** Three.js (3D), GSAP (Animaciones), Chart.js (Datos).
*   **Estilos:** Bootstrap 5 + Custom CSS (Premium Glassmorphism).
*   **Base de Datos:** Firebase Firestore.
*   **Infraestructura:** Docker + Render.

## 💻 Instalación Local

1. **Clonar y Entrar:**
   ```bash
   git clone https://github.com/StartDevSystems/Sistema_Cotizaci-n.git
   cd Sistema_Cotizaci-n
   git checkout v2-premium-visuals
   ```

2. **Entorno:**
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Ejecutar:** `python app.py`
